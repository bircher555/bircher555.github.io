创建博客

1.安装git和node.js

2.桌面右键(显示更多选项)看到git即为git安装成功

3.cmd窗口中输入node -v出现版本号即为node安装成功

##提示node不是最新版本可以在cmd窗口中输入npm install -g npm@X.X.X进行更新##

4.新建一个名为hexo的文件夹

5.进入文件夹

6.右键唤出git，点击Git Bash Here

7.打开hexo官网

8.复制网页底下的第一行命令，回车

##运行时间有点长(也没多久)，耐心等一会，再次出现和第一行一样的输入指令(就绿紫黄那个)即为运行结束##

9.复制网页底下的第二行命令，回车，没报错即为成功

##此时hexo文件夹中会出现blog文件夹##

10.复制网页底下的第三行命令，回车

11.复制网页底下的第四行命令，回车

12.复制网页底下的第五行命令，回车

13.hexo s 可以看到博客地址了

14.在blog根目录里右键打开GBH

15.hexo new “标题”新建一篇文章

##可以在source——>_posts文件夹中找到这篇文章##

##用记事本打开，窗口底下先改成正常格式编辑，再改为MD语法，保存##

16.hexo g 生成网页

17.hexo s 运行博客

18.在github中创建新仓库地址改为“昵称.github.io”

19.在blog根目录中打开GBH输入npm install –save hexo-deployer-git

20.打开_config.yml

##用记事本打开##

21.type:(空格) git

22.添加repo:(空格) 仓库地址

23.添加branch:(空格) master

24.保存退出

25.hexo d 部署到远端

26.hexo clean 清理(没反应就清一下)

27.在github中打开设置，找到pages顶头即为博客地址

我的大学生活初体验：作为江苏大学智能制造工程学子的起点

今天是 2025 年 8 月 28 日，距离正式踏入江苏大学的校园越来越近，作为 25 届智能制造工程学院的一名新生，我既期待又充满好奇，于是写下这篇文章，记录此刻的心情与对未来的规划。

一、选择智能制造工程的初衷

之所以选择这个专业，一方面是因为感受到了当前工业领域“智能化转型”的大趋势——小到家里的智能家电，大到工厂里的工业机器人、数字孪生生产线，“智能制造”正在改变我们的生活和生产方式；另一方面，江苏大学在工科领域的口碑和智能制造工程学院的课程设置（如工业机器人技术、智能检测等），也让我相信能在这里学到扎实的专业知识。

二、对大学生活的期待

  1. 专业学习：希望能尽快适应大学的课程节奏，尤其学好数学、机械基础、编程等核心基础课，为后续的专业深入学习打牢地基；
  2. 实践探索：希望加入未工协，为大学生活和未来添上浓墨重彩的一笔；
  3. 人际交往：期待认识来自全国各地的同学和专业老师，在小组作业、社团活动和竞赛中互相学习，共同成长。

三、短期小目标

  • 开学前：提前预习《高等数学》基础内容）；
  • 大一上学期：加入 1-2 个与专业相关的社团（如机器人协会），争取期末成绩达到专业前 30%，通过4级考试；
  • 寒假：尝试联系学长学姐，了解专业实习或科研项目的入门路径。

未来的日子还长，希望自己能保持这份热情，在江苏大学的校园里，一步步靠近“成为工程领域实用型人才”的目标。
